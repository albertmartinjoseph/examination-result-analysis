# Examination Result and Academic Performance Analysis Using Python

## About the Project
This project analyses student examination results using Python. It uses Pandas, NumPy and Matplotlib to calculate statistics and create visualizations that help understand students' academic performance.

## Dataset
The project uses the Students Performance in Exams dataset from Kaggle.

Dataset link: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

## Features
- Displays and examines student data.
- Calculates average, highest and lowest marks.
- Calculates subject-wise pass percentages.
- Analyses grade distributions.
- Compares performance across subjects.
- Displays charts and graphs.
- Identifies the subject with the lowest average score.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Keep `StudentsPerformance.csv` in the same folder as the notebook.
4. Open `Examination_Result_Analysis.ipynb` in Jupyter Notebook.
5. Run all cells from the beginning.
